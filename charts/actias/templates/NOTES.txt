Ingress is disabled; reach the console with two port-forwards. The
console's browser calls go to the api directly, and with no ingress it
was told to expect it on localhost:3001, so both are needed:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "actias.fullname" . }}-web 3000:3000
  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "actias.fullname" . }}-api 3001:3000

Scripts serve by path prefix on any worker:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "actias.fullname" . }}-worker 3002:3000
  curl http://localhost:3002/<identifier>/
