## Declare

```lua
local visits = kv "visits"
```

Top level only. Scoped to the project, so two scripts in one project
declaring `kv "visits"` share it.

## Methods

```lua
ns:get("hits")                          -- value, or nil
ns:set("hits", 41)
ns:set_batch({ hits = 41, banner = { text = "back at 09:00" } })
ns:delete("hits")
```

<table>
  <thead>
    <tr><th>Method</th><th>Returns</th></tr>
  </thead>
  <tbody>
    <tr><td><code>get(key)</code></td><td>the value, or nil</td></tr>
    <tr><td><code>set(key, value)</code></td><td>nothing</td></tr>
    <tr><td><code>set_batch(table)</code></td><td>nothing; writes every pair, deletes the nil ones</td></tr>
    <tr><td><code>delete(key)</code></td><td>nothing</td></tr>
  </tbody>
</table>

## Types

kv stores the type you wrote and returns it.

<table>
  <thead>
    <tr><th>You write</th><th>You get back</th></tr>
  </thead>
  <tbody>
    <tr><td>string</td><td>string</td></tr>
    <tr><td>integer</td><td>integer</td></tr>
    <tr><td>number</td><td>number</td></tr>
    <tr><td>boolean</td><td>boolean</td></tr>
    <tr><td>table</td><td>table, through JSON</td></tr>
  </tbody>
</table>

## Example

```lua
local cache = kv "cache"

on "fetch" (function(request)
    local hits = (cache:get("hits") or 0) + 1
    cache:set("hits", hits)
    return { body = tostring(hits) }
end)
```

### Gotchas

- There is no listing and no query. Every value must be reachable by a
  key you can construct.
- Functions and userdata cannot be stored. Tables go through JSON, so
  what comes back is a copy, not the table you put in.
- A nil value in `set_batch` is a delete, not a stored nil.
