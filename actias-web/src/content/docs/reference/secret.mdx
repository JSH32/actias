## Declaring

```lua
local signing = secret "jwt-signing-key"
```

The value resolves when used. Set it with the CLI or the console; it
never lives in the bundle.

```sh
actias secret <project-id> put jwt-signing-key <value>
```

## Rotation

Putting a new value creates a new version. Later resolutions get the
new one.

A [workflow](/docs/reference/workflow) run pins the version it first
resolved, so a long run keeps signing with one key even if the secret
rotates while it is parked.

## Example

```lua
local signing = secret "jwt-signing-key"

local function tokens()
    return Jwt.new("HS256", signing)
end

on "fetch" (function(request)
    local token = tokens():encode({ sub = "ada", exp = os.time() + 3600 })
    return { body = token }
end)
```

Build the signer inside the handler. The top level is the declaration
pass, where runtime surfaces are inert.

## Console

The secrets view shows names, versions, who declared them, and which
scripts reach them. Values are never shown after they are set.
