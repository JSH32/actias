You write a Lua file and publish it. It answers HTTP requests.

```lua
local visits = kv "visits"

on "fetch" (function(request)
    local count = (visits:get("count") or 0) + 1
    visits:set("count", count)
    return {
        headers = { ["content-type"] = "application/json" },
        body = json.stringify({ hello = "actias", visits = count }),
    }
end)
```

That is the whole program. No package file, no database setup, no
connection string: storage, background jobs, scheduled work and live
updates are part of the runtime, not services you attach.

## Declarations

`kv "visits"` declares that this script uses a key-value namespace
called `visits`. Databases, queues, workflows, object classes and
secrets are declared the same way, at the top level of the entry point.

A script can only reach what its declarations name. Ask for a namespace
you never declared and the call fails.

The platform derives the list by running your file with every surface
stubbed out, then stores it with the revision. `actias check` prints
the same list locally before you publish.
