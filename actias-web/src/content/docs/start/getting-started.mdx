## Get the tools

The CLI is one binary, `actias`. Take it from the download page or
build it from the repository:

```sh
cargo build -p actias-cli
```

You also need somewhere to publish to. Locally that is
`docker-compose up -d` in the repository root, which boots the api, the
console, workers and storage.

## Log in and make a project

```sh
actias login          # asks for the api url and your credentials
actias project create my-project
```

A **project** owns your scripts and everything they declare. The kv
namespaces, databases, objects and secrets a script uses are scoped to
it.

## Create a script

```sh
actias init hello
cd hello
```

Open `main.lua`:

```lua
on "fetch" (function(request)
    return {
        headers = { ["content-type"] = "application/json" },
        body = json.stringify({ hello = "actias" }),
    }
end)
```

## Check it

```sh
actias check
```

```
📜 Project validated!
⚡ Handles events: fetch
🔎 Types check out (luau-analyze).
```

`check` runs the same declaration pass the server runs at publish, then
type-checks every file. Anything the platform would reject fails here
first.

As your script grows the printed list grows with it: the kv namespaces,
databases, queues, workflows, object classes and streams it declares.
The console shows the same list, and the server enforces it.

## Publish it

```sh
actias publish
```

Only changed files upload. The server derives the contract from your
code again, the revision goes live, and the CLI prints the public
identifier and the revision id.

Your script answers at `<worker-url>/<identifier>/`:

```sh
curl http://localhost:3002/hello/
{"hello":"actias"}
```

## Add something that remembers

Declare a key-value namespace at the top level and use it inside the
handler:

```lua
local visits = kv "visits"

on "fetch" (function(request)
    local count = (visits:get("count") or 0) + 1
    visits:set("count", count)
    return {
        headers = { ["content-type"] = "application/json" },
        body = json.stringify({ visits = count }),
    }
end)
```

Publish again and refresh a few times. The counter survives requests,
restarts and deploys, and the console's KV section shows it changing.
